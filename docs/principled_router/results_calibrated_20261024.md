# 学习版似然与按 slice 校准的 unknown(2026-10-24 PT)

## 做了什么

`eval/streaming_sst/principled_router/embed_pseudo.py` 从 10 个 1k slice 的 glossary 造弱监督数据:每个 slice 600 条伪上下文,每条是随机抽 3–12 个中文译名用"、"连接。**评测 talk 的 gold 条目被排除**:nlp slice 里有 238 条 `acl_tagged_gt`(取自 ACL dev 五篇,正是 replay 的 talk),medicine slice 里有 212 条 `medicine_hard_llm_judge_manual`(取自 ESO 五篇);不排除就是直接泄漏。剩 nlp 762、medicine 788、其余各 1,000 条。

`calibrated_eval.py` 把三种打分统一进同一个 HMM:每个 slice 的分数在**该 slice 自己的留出伪上下文**上标准化成 z 分数,似然 κ·z_k,unknown 为 κ·z0。z0 原本的含义是尾部分位(z0 = −2 即"比该 slice 98% 的自身上下文都远"),用来替代全局余弦常数 c_u。三种打分:

- desc:到手写描述 prototype 的余弦(与上一轮相同的 prototype,只换校准);
- data:到伪上下文均值的余弦(数据驱动 prototype);
- logreg:多项 logistic 回归 logit(C 由 5 折 CV 选出 3.73;伪上下文留出准确率 93.6%)。

其余参数固定为上一轮交叉验证选中的值(λ = 1/600 s⁻¹、τ = 0.01、w = 8、B = 4),扫 κ ∈ {0.5,1,2,4,8} × z0 ∈ {−3 … 0}。完整网格在 `calibrated_replay.json`。

## 结果

未知领域的权衡前沿(在已知领域覆盖率不低于给定值的配置里,取被删领域窗口拒识率的最大值):

| 方法 | 删 NLP:拒识 @ 覆盖 ≥95% / ≥90% | 删 medicine:拒识 @ ≥95% / ≥90% |
|---|---|---|
| 裸余弦 + 全局 c_u(上一轮) | 11.4% / 11.4% | 86.2% / 92.3% |
| desc + 按 slice 校准 | 0.5% / 2.6% | 达不到该覆盖 |
| data + 按 slice 校准 | 10.5% / **45.6%** | 83.2% / 83.2% |
| logreg + 按 slice 校准 | 7.8% / 19.1% | 10.4% / 10.4% |

全目录(10 个领域都在):

| 方法 | 最高覆盖率 | 覆盖 ≥95% 时最少平均 slice 数 |
|---|---|---|
| 裸余弦 HMM(上一轮默认点) | 97.8%(1.23 个 slice) | 1.23 |
| desc 校准 | 95.9% | 2.02 |
| data 校准 | 97.2% | 1.50 |
| logreg 校准 | 98.2% | 1.44 |

## 读法

1. **校准的位置失真**。真实译文上下文的 z 分数整体远低于伪上下文:data 打分下 z0 = −2 时覆盖率只剩 17–36%,说明流畅译文离"术语袋"分布有两个标准差以上。z0 因此不再是它名义上的尾部分位,"按 slice 校准让阈值可解释"这一点在弱监督数据上不成立。
2. **学习版没有带来实质提升**。logreg 的最高覆盖率高 0.4 点,但要多装 0.2 个 slice;未知领域上反而更差(删 medicine 时几乎不拒识),因为判别式模型在类间强行分配概率,"不像任何类"的信号被 softmax 抹掉了。
3. **唯一的正面信号**是 data prototype 在删 NLP 方向:90% 覆盖下拒识 45.6%(全局 c_u 只有 11.4%)。但在删 medicine 方向略差,也就是说它改变的是两个方向之间的取舍,不是整体前移。
4. 根因在弱监督数据和测试分布不匹配:术语袋 vs. 流畅译文。更原则的做法是用**真实但无标签的译文**做校准(只估每个 slice 分数分布的位置与尺度,不需要领域标签),例如不在评测里的讲座的译文;目前手头没有这样的数据,用评测 talk 本身做位置校准会构成调参泄漏。

## 结论与决定(记入 decision_log D6)

- 主方法保留上一轮的裸余弦 HMM(描述 prototype + 全局 c_u),它在覆盖率 / slice 数上仍是最好的工作点。
- 学习版作为负结果写进分析:"在术语表弱监督下,判别式似然不优于描述 prototype,且损害未知领域检测"。这本身回答了 reviewer 的"prototype 是手写的"质疑:手写不是瓶颈,数据分布才是。
- unknown 校准的下一步需要无标签真实译文,和相近领域数据是同一个数据缺口(ESO 训练集讲稿 + 公开讲座),合并到数据阶段做。
