AutoTerm-SST

Streaming speech translation that finds its own terminology.

The hosted live demo is offline at the moment.

  • Source repository (MIT licensed), with a mock mode that runs the full interface and protocol without GPUs
  • Screencast of a complete session, including the automatic switch from an ACL talk to a medical lecture
  • Paper on arXiv

The repository README describes how to run the full system on your own GPUs.
